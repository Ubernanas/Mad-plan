# Idéer til senere

Bygges ikke nu. Datamodellen er lavet, så de kan tilføjes (kilopriser gemmes, og `kitchen` har mængde, enhed, placering og holdbarhed).

- **Lagerkøb:** køb holdbare varer i større mængder, når de er på tilbud.

Bygget: **køleskabsskærmen** (`#/skaerm`, se `docs/design.md`).
